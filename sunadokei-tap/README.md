# 砂時計タップ

タップで砂を落とすだけの、片手・無心の暇つぶしブラウザアプリ（スマホ縦持ち専用）。
通信・課金・広告・アカウント登録は一切なし。データは端末のブラウザ（localStorage）にだけ保存されます。

## 起動手順

**スマホで使う（おすすめ：GitHub Pages）**

1. GitHub のリポジトリ画面 → Settings → Pages で、このブランチを公開する
2. スマホのブラウザで `https://<ユーザー名>.github.io/cream_PC/sunadokei-tap/` を開く
3. ブラウザのメニューから「ホーム画面に追加」すると、アプリのように起動できる（2回目以降は圏外でも開けます）

**スマホで使う（同じWi-Fiのパソコンから配信）**

```
cd sunadokei-tap
python3 -m http.server 8000
```

スマホで `http://<パソコンのIPアドレス>:8000/` を開く。

**パソコンで動作だけ確認する**

`sunadokei-tap/index.html` をダブルクリック（クリック＝タップ）。

## 使い方

- **画面をタップ** … 砂が落ちる。**長押し**でも流れつづける（親指を置くだけ）
- タップした側へ砂の流れが少し寄り、山の形がすこしずつ変わる
- 砂は層ごとに色が変わり、落ちきると自動でひっくり返って次の砂時計へ
- **金の砂**（1タップあたり約1/260）と **遺物**（約1/110：コイン・貝・化石など）がまれに落ちてくる
- 下の **図鑑** ボタン … 砂の色（全20）・遺物（全24）のコレクションと、きろく・設定
- **♪** ボタン … 音のオン/オフ（振動のオン/オフは 図鑑 → きろく）

レア度の出現割合：砂の層は ふつう62%／めずらしい27%／レア9%／幻2%、遺物は 60%／28%／10%／2%。

## データ

- 進行状況とコレクションは自動保存（アプリを閉じても続きから）
- 消したいときは 図鑑 → きろく →「記録をすべて消して最初から」（無料・2回押しで確定）
- ブラウザのサイトデータを消すと記録も消えます

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` / `style.css` | 画面 |
| `app.js` | 砂のシミュレーション・抽選・保存 |
| `data.js` | 砂の色・遺物の定義（名前、確率の重み、ドット絵） |
| `sw.js` / `manifest.webmanifest` / `icon*` | ホーム画面追加・オフライン起動用 |

外部ライブラリ・外部APIは使っていません。
