# レポート構成ナビ

大学レポートの「構成づくり」と「文献検索」を1つの画面で進めるブラウザアプリです。
課題の整理 → 問いを立てる → 構成をつくる → 文献を探す → 引用を整える、の5ステップで進みます。

> **本文は自分で書く前提のツールです。**
> 出すのは構成（骨組み）・書く内容の要点・引用形式の雛形だけで、文章の代筆や文献の文章の写しは行いません。

- インストール・ビルド・APIキー・ユーザー登録は不要
- 入力内容はブラウザの中（localStorage）だけに保存
- 外部と通信するのは文献検索を実行したときだけ（送るのは検索語と絞り込み条件のみ）
- PC・スマホ両対応（PCは左メニュー、スマホは下タブ）

---

## 1. 起動手順

### PCで使う

1. `report-navi` フォルダをまるごと保存します（GitHubなら「Code」→「Download ZIP」→展開）。
2. フォルダ内の **`index.html` をダブルクリック**します。ブラウザで開けば準備完了です。

`index.html`・`style.css`・`js/` は同じフォルダに入れたままにしてください。

### スマホで使う

スマホではファイルを直接開けないため、次のどちらかで配信します。

- **GitHub Pages などに置く**：フォルダの中身をそのまま公開し、そのURLをスマホで開く。
- **同じWi-Fi内のPCから配信する**：PCで下のコマンドを実行し、スマホで `http://（PCのIPアドレス）:8000/` を開く。

  ```bash
  cd report-navi
  python3 -m http.server 8000
  ```

データは「端末ごと・ブラウザごと・開き方（URL）ごと」に別々に保存されます。

## 2. 使い方

| ステップ | すること |
| --- | --- |
| 1 課題 | テーマ／課題文／字数／種類（論述・実験・書評・調査）を入力。課題文から「論じる」「比較する」などの指示語と字数を読み取って表示します。 |
| 2 問い | 対象・範囲・観点などをメモすると、問いの型（原因・影響・比較…）にあてはめた候補が出ます。選んで自分の言葉に直すと、疑問文か・広すぎないか等を自動チェックします。仮の答え（主張）もここで書きます。 |
| 3 構成 | 序論 → 本論（主張＋根拠＋反論）→ 結論の骨組みを生成。各セクションに「何を書くか」と目安字数が付きます。論点の数・字数・並び・題名は変更でき、要点メモと使う文献を書き込めます。「構成メモをコピー／テキストで保存／印刷」で持ち出せます。 |
| 4 検索 | タブで検索先を切り替え、結果（タイトル・著者・年・リンク）から「＋ 文献リストへ」で保存します。 |
| 5 引用 | 保存した文献を引用形式の雛形に整えます（日本語・一般／APA 第7版／SIST02／IEEE）。文献リスト用と本文中用をそれぞれコピーできます。書誌情報の修正と手入力での追加も可能です。 |

画面上部（スマホ）／左上（PC）で、レポートの切り替え・新規作成ができます。「⋯」メニューから表示テーマの変更、バックアップの書き出し・読み込み、レポートの削除ができます。

## 3. 文献検索について

| タブ | 検索先 | 向いているもの |
| --- | --- | --- |
| 理系・全分野 | [Semantic Scholar](https://www.semanticscholar.org/) Academic Graph API | 英語論文全般。被引用数・無料PDFの有無が分かる。英語のキーワードが有効。 |
| 文系・日本語 | [CiNii Research](https://cir.nii.ac.jp/) OpenSearch API | 日本語の論文・図書・博士論文。種別・並び順・本文リンクの有無で絞り込み可。 |

- どちらもキー・登録なしで、ブラウザから直接呼び出します。
- **Semantic Scholar はキーなしの共有枠のため、混雑時は結果を取得できないことがあります。** アプリは自動で4回まで再試行し、それでも取れないときは「もう一度検索」「CiNii Research で同じ語を検索」「Semantic Scholar のサイトで開く」を案内します。
- 要旨は「読む文献を選ぶ」ための表示です。引用する前に必ず本文を確認してください。

## 4. 引用の雛形について

- 取得できなかった項目は `〔巻(号)〕` のように〔 〕で残ります。原典を見て埋めてください。
- 著者名の姓・名は自動判定です。違っていたら「書誌情報を直す」で `姓, 名` の形に直すと確実です。
- 日本語の著者名は読み（五十音）で並べ替えられません。提出前に並びを確認してください。
- 授業・学部で書式の指定がある場合は、そちらを優先してください。

## 5. データの保存

- 保存先：ブラウザの localStorage（キー `reportNavi.v1`）。サーバーには送られません。
- ブラウザの履歴・サイトデータを消すと、入力内容も消えます。「⋯」→「書き出す（JSON）」でバックアップできます。
- プライベートブラウズなど保存が使えない環境では、画面上部に注意が出ます。

## 6. ファイル構成

```
report-navi/
├── index.html      画面の枠
├── style.css       見た目（ライト／ダーク、PC／スマホ）
├── js/
│   ├── data.js     問いの型・構成の型（種類ごとの案内文）
│   ├── cite.js     引用形式の整形
│   ├── search.js   Semantic Scholar／CiNii Research の呼び出し
│   └── app.js      画面の動きと保存
└── README.md
```

素の HTML / CSS / JavaScript だけで、外部ライブラリは使っていません。
