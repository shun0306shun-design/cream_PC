# 講座・集客ツール

北海道・道東の地域密着ビジネス向けの「講座＋集客 一体型」Webツールです。
料金の見積もり、講座カリキュラムづくり、チラシ・案内文づくり、つまずきQ&A、予約・進捗メモ、設定の6つが、1つの画面にまとまっています。

- インストール不要・インターネット不要（オフラインで動きます）
- 外部のサービスやAPIは使いません。入力した内容は、外に送信されません
- スマホ優先のつくりで、パソコンでも使えます

---

## 1. 起動手順

1. このフォルダを、まるごとパソコンに保存します。
   （GitHubから取る場合：緑色の「Code」→「Download ZIP」→ できたZIPファイルを右クリックして「すべて展開」）
2. フォルダの中の **`index.html` をダブルクリック** します。
3. ブラウザ（Chrome・Edge・Safari など）でツールが開きます。これで準備は終わりです。

注意すること

- `index.html`・`style.css`・`app.js`・`data.js` の4つは、**同じフォルダに入れたまま**にしてください（1つでも欠けると動きません）。
- 次に使うときも、同じ `index.html` を開いてください。毎回ひらきやすいよう、ブラウザの「お気に入り（ブックマーク）」に入れておくと便利です。
- スマホで使いたい場合は、フォルダの中身をそのままWebサーバー（GitHub Pages など）に置き、そのアドレスをスマホで開きます。データは「機械ごと・ブラウザごと」に別々に保存されます。

## 2. 画面の見かた

画面の下（パソコンでは上）に6つのタブがあります。押すと機能が切りかわります。

| タブ | 機能 |
| --- | --- |
| 料金 | 料金シミュレーター（見積書） |
| 講座 | 講座カリキュラムづくり |
| チラシ | チラシ・案内文づくり |
| Q&A | つまずきQ&A |
| 予約 | 予約・進捗メモ |
| 設定 | お店の情報・単価・文字の大きさ・バックアップ |

## 3. 各機能の使い方

### 料金シミュレーター（「料金」タブ）

1. 上の「Web制作」「講座」のどちらかをえらび、ページ数・回数・人数や、追加するものをえらびます。
2. すぐ下に、見積書の形で金額が出ます（Web制作は初期費用と月額、講座は合計と1人あたり）。
3. 「印刷する」で印刷、「文章をコピーする」でコピー、「予約・進捗メモに登録する」でそのまま案件として記録できます。

### 講座カリキュラムづくり（「講座」タブ）

1. 対象（初心者・シニアなど）、回数（1〜8回）、1回の時間、テーマ（いくつでも）をえらびます。
2. 全回のタイトル・内容・持ち物・到達ゴールが表で出ます（スマホでは1回分ずつのカードで表示）。
3. 「印刷する」「文章をコピーする」が使えます。「この講座名でチラシを作る」で、チラシづくりへ進めます。

### チラシ・案内文づくり（「チラシ」タブ）

1. 講座名・日時・場所・料金・定員・申込方法・一言PRを入れ、文体（やさしい／きちんと）をえらびます。
2. ①A4チラシ、②LINE・SNS用の短い告知文、③回覧板・掲示用の案内文の3つが、同時にできあがります。
3. それぞれに「印刷」と「コピー」のボタンがあります。「記入例を入れてみる」で見本をためせます。

### つまずきQ&A（「Q&A」タブ）

1. 「キーワードでさがす」に言葉を入れるか、カテゴリのボタン（LINE・AI・写真・設定・詐欺・安全など）でしぼりこみます。
2. 質問を押すと答えがひらきます。最初から48件のQ&Aが入っています。
3. 「＋ 新しいQ&Aを追加する」で追加、ひらいた答えの下のボタンで「直す」「削除する」ができます。

### 予約・進捗メモ（「予約」タブ）

1. 「＋ 新しく登録する」から、名前・種別（Web制作／講座予約）・日付・金額・ステータス・メモを入れて保存します。
2. 一覧では、ステータスや種別でのしぼりこみ、日付順の並べかえ、ステータスの変更、「内容を直す」「削除する」ができます。
3. Web制作が同じ月に重なって「月1件まで」を超えそうなときは、入力の窓と一覧の上に注意が出ます。

### 設定（「設定」タブ）

1. 「お店の情報」に店名・連絡先・住所・ロゴ画像を登録すると、印刷物の下に自動で入ります（空なら何も入りません）。
2. 「文字の大きさ」は標準／大／特大から、「料金の単価」は金額を書きかえて変えられます。
3. 「バックアップ」でデータの書き出し・読み込み、「初期データにもどす」でリセットができます。

### 印刷のコツ

- 「印刷する」を押すと、ブラウザの印刷画面がひらきます。用紙は **A4・縦** をえらんでください。
- 印刷画面の「ヘッダーとフッター」のチェックを外すと、日付やファイル名が入らず、きれいに仕上がります。
- 色つきの枠もそのまま印刷したいときは、「背景のグラフィック」にチェックを入れます（白黒でも読めるつくりです）。

## 4. データの保存場所とバックアップ

### 保存場所

データはすべて、**いま使っているブラウザの中（localStorage）** に保存されます。インターネット上には保存されません。

| キー | 中身 |
| --- | --- |
| `dotokoza_settings` | 店名・連絡先・住所・ロゴ・文字の大きさ |
| `dotokoza_prices` | 料金の単価・月の上限件数 |
| `dotokoza_qa` | つまずきQ&A |
| `dotokoza_records` | 予約・進捗メモ |
| `dotokoza_forms` | 入力途中の内容（見積もり・カリキュラム・チラシ）と最後に開いたタブ |

次のときはデータが見えなくなるので、こまめにバックアップしてください。

- ブラウザの「閲覧履歴やサイトのデータを消す」操作をしたとき
- 別のブラウザ・別のパソコン・スマホで開いたとき（データは共有されません）
- フォルダの置き場所や名前を変えたとき（ブラウザによっては別のものとして扱われます）
- 「シークレット（プライベート）」の画面で使ったとき

### バックアップのしかた

1. 「設定」→「バックアップ」→ **「データを書き出す」** を押します。
2. `kouza-tool-backup-日付.json` というファイルが、「ダウンロード」フォルダに保存されます。USBメモリなどにも写しておくと安心です。
3. 元にもどすときは **「データを読み込む」** を押して、そのファイルをえらびます（いまのデータは置きかわります）。

別のパソコンへ引っ越すときも、同じ手順（書き出す → 新しいパソコンで読み込む）で移せます。

## 5. 前提・仮定にしたこと

質問をせずに作るため、次のことはこちらで決めました。金額やルールは「設定」で変えられます。

### 料金の初期値（地方の低価格帯を想定した仮の金額）

| 区分 | 項目 | 初期値 |
| --- | --- | --- |
| Web制作 | 基本料金（トップページ1枚・スマホ対応こみ） | 30,000円 |
| Web制作 | 追加ページ（1ページあたり） | 8,000円 |
| Web制作 | 写真撮影（出張1回） | 10,000円 |
| Web制作 | お問い合わせフォーム | 5,000円 |
| Web制作 | Googleマップへのお店登録 | 5,000円 |
| Web制作 | ドメイン・サーバー手続き代行（最初の設定） | 5,000円 |
| Web制作 | ドメイン・サーバー管理（実費こみ） | 月1,500円 |
| Web制作 | 更新代行 ライト（月1回まで） | 月3,000円 |
| Web制作 | 更新代行 しっかり（月4回まで） | 月6,000円 |
| 講座 | グループ講座（1人・1回） | 1,500円 |
| 講座 | 個別講座（1人・1回） | 3,000円 |
| 講座 | 出張費（1回） | 1,000円 |
| 講座 | テキスト代（1人） | 300円 |
| 講座 | 回数割引 | 4回以上で受講料を10％引き |

### 料金・見積もり

- 金額は「お支払いの総額（概算）」として表示し、消費税の内訳は出しません（税込価格、または免税事業者を想定）。
- 見積書の有効期限は「発行日から1か月」と記載しています。
- 講座の「1人あたり」は、合計を人数で割り、1円未満を切り上げています。回数割引は受講料だけにかかります（出張費・テキスト代は対象外）。
- 講座の見積もりは1〜12回・1〜30人、Web制作は1〜20ページまでえらべます。
- 写真撮影・お問い合わせフォーム・Googleマップ登録は、依頼文の「など」にあたる項目として追加しました。

### 講座カリキュラム

- 対象は4種類（初心者／シニア／少し使える方／お店・事業をしている方）、テーマは7種類（LINE・AI活用・Instagram・写真・詐欺対策・スマホの基本・暮らしの便利）。各テーマに5回分のひな形があります。
- 回数がテーマ数より少ないときは1回に複数テーマをまとめ、回数がひな形より多いときは「おさらい」「自由課題」の回を足します。
- 対象によって、初回の導入・毎回のおさらい・持ち物・応用の一言が変わります。
- 内容は一般的な進め方の案です。実際の受講者に合わせて調整してください。

### チラシ・案内文

- 日時は自由に書ける欄にしました（「毎週土曜 全4回」などにも対応するため）。曜日のまちがいを防ぐ「カレンダーから日時を入れる」も付けています。
- A4チラシは、用紙1枚におさまるように文字の大きさを自動で調整します。
- 「きちんと」の案内文は日付を和暦（令和）で、「記／以上」の形式で出します。
- LINE・SNS用の告知文をコピーしたときは、店名・連絡先を文字で末尾に入れます（ロゴは画像なので、画面と印刷にだけ入ります）。

### 予約・進捗メモ

- 「月1件まで」は、登録した**日付の月**ごとに数えます。「契約・制作中・完了」を決まった案件、「問合せ・見積」を候補として、超えそうな段階から注意を出します。
- 上限を超えても保存はできます（確認が出ます）。上限の件数は「設定」→「受付のルール」で変えられます。
- ステータスの4つ目は、種別に合わせて「制作中」（Web制作）／「受講中」（講座）と表示します。
- 最初は登録が空の状態です（見本のデータは入れていません）。

### 設定・画面

- 連絡先とは別に「住所」の欄を追加しました（空欄でもかまいません）。
- ロゴは、長い辺が480px以下になるよう縮小し、200KB以下になるまで自動で小さくします（透明な部分はできるだけ残します）。
- 文字の大きさは、標準18px／大21px／特大24px。「大」「特大」のときは、スマホのタブが2段になります。
- 印刷物の下の店名などは、依頼どおり小さめの文字にしています（ここだけ18px未満）。
- 単価・お店の情報は、入力欄から離れた時点でも自動で保存します。見積もり・カリキュラム・チラシの入力途中の内容も自動で残ります。
- localStorage のキーの接頭辞は `dotokoza_` です。

### そのほか

- 動作を確かめたのは最近のChrome系ブラウザです。Edge・Safari・Firefoxの新しい版でも動く作りにしています。
- 文章を「言葉の切れ目」で折り返す表示は、対応しているブラウザ（Chrome・Edge）だけで働きます。ほかのブラウザでは通常の折り返しになります。
- Q&Aの答えは一般的な案内です。機種やアプリの版によって画面の言葉がちがうことがあるので、講座で使いながら書きかえてください。

## 6. 今後の拡張案

1. **受講者名簿と出欠の記録**：予約メモから講座ごとの名簿を作り、出欠と「できたこと」を残す。
2. **月ごとの集計と書き出し**：売上・件数の月別まとめと、表計算ソフトで開けるCSVの書き出し。
3. **チラシのデザイン選択**：色ちがい・写真入り・地図やQRコード入りなど、ひな形を増やす。

## 7. ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `style.css` | 見た目と印刷（A4）の設定 |
| `app.js` | 動きの本体（計算・生成・保存） |
| `data.js` | 初期データ（単価・カリキュラムのひな形・文例・Q&A） |
| `README.md` | この説明書 |

初期データを変えたいときは `data.js` を書きかえます（Q&Aの追加や単価の変更は、画面からもできます）。
