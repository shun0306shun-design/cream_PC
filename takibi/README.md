# 焚き火くべ

片手・無心で薪をくべて火を育てる、スマホ専用のブラウザアプリです。
通信・課金・広告・アカウントは一切なし。記録は端末の localStorage にだけ保存します。

## 起動手順

ビルド不要です。この `takibi` フォルダを静的ファイルとして開くだけで動きます。

**スマホで遊ぶ（おすすめ）**

1. PCでこのフォルダに移動して簡易サーバーを起動
   ```
   cd takibi
   python3 -m http.server 8000
   ```
2. 同じWi-Fiにつないだスマホのブラウザで `http://<PCのIPアドレス>:8000/` を開く
3. ブラウザの「ホーム画面に追加」をすると、全画面のアプリとして起動できます

GitHub Pages などの静的ホスティングにフォルダごと置いても同じように動きます。

**PCで動作確認だけする**

`index.html` をダブルクリックし、ブラウザの開発者ツールでスマホ表示（縦向き）にします。

> 記録は「開いたURLごと・ブラウザごと」に別々に保存されます。

## 使い方

- **薪をくべる**：画面のどこか、または下の「くべる」ボタンをタップ。長押しで連続してくべられます
- **火力**：火は時間とともに小さくなります。「くべる」ボタンの外周リングが今の火力です
  （熾火 → 種火 → 小さな火 → 焚き火 → 大きな焚き火 → 天を焦がす炎）
- **中断**：アプリを閉じても熾火は消えません。いつでも続きから始められます
- **下のボタン**（すべて親指の届く位置）

  | ボタン | はたらき |
  | --- | --- |
  | 図鑑 | 出会ったレアな出来事のコレクションと、できごとログ |
  | 空 | 自動 → 夜 → 朝 の切り替え（自動は 5:00〜16:59 が朝、それ以外が夜） |
  | 音 | 焚き火の音・効果音の ON / OFF（**初期状態は OFF**） |
  | 設定 | 音・振動・空の設定、これまでの記録、記録の消去 |

## レアな出来事（全12種）

出会うと図鑑（種類・回数・初めて出会った日時）とログ（直近100件）に残ります。

| 出来事 | 出会える条件 |
| --- | --- |
| 青い炎 ★ / 翠の炎 ★ / 紫の炎 ★★ / 桜色の炎 ★★ / 虹色の炎 ★★★ | 薪をくべたとき、まれに |
| 火の粉花火 ★ / 大輪の花火 ★★★ | 薪をくべたとき、まれに（大輪は大きな火のときだけ） |
| 流れ星 ★ / 流星群 ★★★ | 夜、火が燃えている間 |
| 朝の虹 ★★ / 朝露の精霊 ★★★ | 朝、火が燃えている間 |
| 火の精霊 ★★ | 「焚き火」以上に育った火のそばに |

抽選は「薪をくべたとき（連打しても毎秒1回まで）」と「火が燃えている間の10秒ごと」。
1回あたりの確率は ★ 0.4〜3%、★★ 0.15〜1%、★★★ 0.03〜0.3% です。

## データについて

- 保存先はブラウザの localStorage（キー：`takibi-kube.v1`）のみ。外部には何も送信しません
- 設定 →「記録をすべて消す」でいつでも無料で初期化できます（2回タップで実行）
- 課金・広告・ガチャ・リセットチケットの類はありません

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | アプリ本体（外部ライブラリ・素材ファイルなし。絵と音はすべてコードで生成） |
| `manifest.webmanifest` / `icon*.png` / `icon.svg` | ホーム画面に追加したときの名前とアイコン |

開発メモ：URLの末尾に `?debug` を付けると、ブラウザのコンソールから `takibi.fx('rainbow')` のように演出をプレビューできます（図鑑には記録されません。ID一覧は `takibi.ids`）。
