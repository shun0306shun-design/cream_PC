# 石ころころ

石を指でころがすだけの、片手・無心ひまつぶしアプリです（スマホのブラウザ専用）。

- インストール不要。外部API・アカウント・通信なし
- 課金・広告・ガチャ課金・リセットチケットは一切なし
- 集めた石は、その端末のブラウザ（localStorage）にだけ保存

---

## 起動手順

スマホで開くには、このフォルダをどこかのWebサーバーに置きます。次のどちらかが手軽です。

### A. GitHub Pages（おすすめ・無料）

1. GitHubのリポジトリ画面 →「Settings」→「Pages」
2. 「Branch」でこのフォルダが入っているブランチと `/ (root)` を選び「Save」
3. 数分後、スマホで `https://<ユーザー名>.github.io/<リポジトリ名>/ishikorokoro/` を開く
4. ブラウザのメニューから「ホーム画面に追加」すると、全画面のアプリのように使え、オフラインでも開けます

### B. 自分のパソコンから配る（同じWi-Fi内）

1. パソコンでこのフォルダを開き、次を実行（Pythonが入っていれば動きます）

   ```
   python3 -m http.server 8000
   ```

2. スマホのブラウザで `http://<パソコンのIPアドレス>:8000/` を開く

> パソコンで見た目だけ確かめたいときは、`index.html` をダブルクリックでも動きます（マウスで操作できます）。

## 使い方

| 操作 | 起きること |
| --- | --- |
| 石にさわって動かす | 石をつかんで、ころがす・はじく・投げる |
| 石からはなれた所をおさえる | 石がそこへ、ころころ寄ってくる |
| 右下の棚ボタン | 集めた石の棚（図鑑）をひらく。まわりの輪は、いまの石の仕上がり具合 |
| 左下の音ボタン | 音のオン・オフ |

- ころがした分だけ石の角が取れ、つやが出ます。仕上がると自動で棚にならび、次の石が落ちてきます。
- 背景は 野原 → 坂 → 水辺 → 谷 → 小川 → 坂 → 浜辺 と、ごくゆっくり移り変わります（朝・昼・夕方・夜も）。
- 棚の石をタップすると、説明と集めた数が見られます。
- 棚の「設定」で、音・振動・ボタンの位置（左手用／右手用）・データ消去ができます。

### 石の種類（全28種）

| 分類 | 数 | 出会える確率（石ひとつごと） |
| --- | --- | --- |
| ふつうの石 | 14 | 残りすべて（景色によって出やすい石が変わる） |
| 宝石（石が宝石に化ける） | 6 | 4% |
| 化石 | 4 | 3% |
| 隕石（空から落ちてくる） | 3 | 0.6%（夜は 2.8%） |
| 黄金の石 | 1 | 0.4% |

ふつうの石が30こ続いたら、次はかならず めずらしい石になります。
確率は `app.js` 冒頭の `RATE` で変えられます。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` / `style.css` | 画面 |
| `app.js` | 本体（操作・物理・景色・保存・音） |
| `stones.js` | 石28種のデータと絵（すべてコードで描画） |
| `sw.js` / `manifest.webmanifest` / `icon-*.png` | ホーム画面追加・オフライン用 |

すべて同じフォルダに置いたまま使ってください。画像・音声・外部ライブラリは使っていません（音はブラウザ内で合成）。

## データについて

- 保存先は、開いたブラウザの localStorage（キー名 `ishikorokoro.v1`）だけです。
- 端末やブラウザを変えると、棚は別々になります。ブラウザの「サイトデータ削除」を行うと消えます。
